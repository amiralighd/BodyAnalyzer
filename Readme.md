# BodyAnalyzer

BodyAnalyzer is a Django-based web application for analyzing basic body and health-related data.

## Features

- User registration
- User login and logout
- User dashboard
- BMI calculation
- Display of BMI results
- Blood sugar reference ranges
- Cholesterol reference ranges
- About page
- Contact page
- Custom user model with phone number authentication

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS
